# Half Adder using Verilog HDL

A simple implementation of a **Half Adder** in Verilog HDL using three different modeling styles:

* Dataflow Modeling
* Gate-Level Modeling
* Behavioral Modeling

The project also includes a testbench for simulation and verification in Vivado.

---

## 📌 Project Overview

A Half Adder is a combinational logic circuit that performs the addition of two single-bit binary numbers.

### Inputs

* A
* B

### Outputs

* Sum
* Carry

### Boolean Expressions

**Sum = A ⊕ B**

**Carry = A · B**
